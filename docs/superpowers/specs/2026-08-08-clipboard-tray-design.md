# PasteOrbit 托盘入口设计

## 目标

为 PasteOrbit 增加 Windows 托盘入口。主窗口失去焦点时仍按现有规则隐藏，但进程继续驻留；用户通过托盘重新打开历史或设置，只有明确选择“退出”才结束进程。

## 交互

- 双击托盘图标：显示、激活并聚焦剪切板历史窗口。
- 右键托盘图标：显示“打开历史”“设置”“退出”三个菜单项。
- 主窗口关闭：取消关闭并隐藏到托盘。
- 托盘“退出”：允许主窗口关闭，释放剪切板监听、全局热键和托盘资源后退出应用。

## 实现边界

- 使用 Win32 `Shell_NotifyIconW`，不引入 WinForms、WPF 或第三方托盘依赖。
- `App` 显式创建主窗口；主窗口隐藏时进程继续驻留，只有托盘“退出”才释放资源并结束进程。
- 托盘菜单由原生菜单创建，主窗口只处理打开历史、设置和退出入口。
- 使用项目内的 `.ico` 资源，并复制到应用输出目录。
- 托盘初始化异常显示在主窗口状态栏，退出路径统一释放资源。

## 验证

- 使用 `dotnet build` 验证 WinUI 3 `net8.0-windows10.0.26100.0` 编译。
- 使用现有核心检查验证历史和剪切板核心逻辑未受影响。
- 手工验证托盘双击、菜单打开/设置/退出，以及主窗口关闭后进程仍驻留。
