# ClipVault 需求设计文档

## 1. 项目概述

ClipVault 是面向 Windows 10/11 的桌面剪切板历史管理器。应用在后台记录文本、图片和文件复制内容，用户可通过全局快捷键打开悬浮面板，搜索历史记录并快速粘贴到当前窗口。

项目采用分阶段交付：第一阶段完成本机剪切板管理 MVP；第二阶段增加局域网同步；第三阶段增加端到端加密的云同步。

## 2. 产品目标

- 减少重复查找、复制和切换窗口的操作成本。
- 让文本、图片和文件历史能够统一检索和再次使用。
- 在不依赖管理员权限和网络服务的情况下完成本机核心功能。
- 通过清晰的同步边界支持后续局域网及云端扩展。
- 默认保护剪切板隐私，不在日志或同步服务中泄露明文内容。

## 3. MVP 范围

### 3.1 剪切板捕获

- 监听文本、图片和文件列表三类 Windows 剪切板内容。
- 保存复制时间、内容类型、来源应用及用于去重的内容指纹。
- 相同内容再次复制时更新时间并移至历史顶部，不产生重复记录。
- 命中排除应用、暂停监听或内容读取失败时不创建记录。
- 短暂遇到剪切板占用时自动有限重试，最终失败则跳过本次事件并写入不含正文的诊断日志。

### 3.2 历史面板

- 默认使用 `Ctrl + Shift + V` 打开悬浮面板，快捷键可配置。
- 历史记录按最近使用时间倒序展示。
- 支持关键词搜索、内容类型筛选和全键盘操作。
- 文本显示摘要，图片显示缩略图，文件显示名称、路径和有效状态。
- `Enter` 或点击记录后，将内容写回剪切板并向原前台窗口发送粘贴操作。
- 自动粘贴失败时保留“已复制”结果，并提示用户手动粘贴。
- 支持置顶、删除、仅复制不粘贴及查看完整内容。

### 3.3 生命周期与设置

- 默认保留最近 30 天且最多 5,000 条普通记录，两项限制均可配置。
- 置顶记录不参与自动过期和数量清理。
- 托盘菜单提供打开面板、暂停或恢复监听、清空历史、设置和退出。
- 重启应用后保留历史、置顶状态和用户设置。
- 卸载时由用户选择保留或删除本地数据。

### 3.4 隐私与安全

- 使用当前 Windows 用户凭据保护本地数据库和内容文件。
- 支持按进程配置排除应用；命中后不读取、不保存对应剪切板内容。
- 支持随时暂停监听和清空历史。
- 日志不得包含剪切板正文、图片内容、文件内容或其他完整敏感数据。
- MVP 不承诺自动准确识别密码输入框或所有敏感内容，主要依赖应用排除、暂停监听和用户标记。

## 4. 非 MVP 范围

第一阶段不包含账号系统、局域网发现、跨设备传输、云端存储、移动端、浏览器扩展及团队共享。MVP 只定义同步接口和必要的数据边界，不实现网络通信。

## 5. 技术设计

### 5.1 技术栈

- .NET 8
- WPF
- SQLite
- Windows 10/11
- 普通用户权限运行

### 5.2 组件边界

- `ClipboardMonitor`：订阅 Windows 剪切板变化并读取支持的数据格式。
- `HistoryService`：负责标准化、去重、置顶、删除和自动清理。
- `LocalRepository`：保存记录元数据及内容引用，执行本地加密和恢复。
- `SearchService`：按正文、文件名、来源应用和内容类型检索。
- `QuickPanel`：处理全局快捷键、悬浮窗口、键盘导航和快速粘贴。
- `PrivacyService`：执行暂停状态、应用排除规则和敏感标记策略。
- `ISyncProvider`：定义后续同步所需的上传、下载、状态及冲突处理边界；MVP 使用无网络实现。

各组件只通过明确接口通信，不让 WPF 视图直接访问数据库或 Windows 剪切板 API。

### 5.3 数据流

捕获流程：检测复制事件 → 检查暂停状态和排除规则 → 读取并标准化内容 → 计算内容指纹 → 合并重复记录或新增记录 → 加密持久化 → 更新面板。

粘贴流程：保存原前台窗口 → 用户选择记录 → 解密并恢复剪切板格式 → 向原窗口发送粘贴操作 → 展示成功或降级提示。

### 5.4 本地数据

- 默认数据目录为 `%LocalAppData%\ClipVault`。
- SQLite 保存记录、类型、时间、来源、指纹、置顶状态和内容引用。
- 大型图片内容单独保存在应用数据目录，数据库只保存加密文件引用和缩略信息。
- 文件类型记录保存路径列表而非复制文件本体；原文件不存在时在界面中标记失效。
- 数据库损坏时保留原文件并创建新库，同时提示用户恢复失败，不静默覆盖原数据。

## 6. 后续阶段

### 6.1 第二阶段：局域网同步

- 同一局域网设备可自动发现，并通过一次性验证码或二维码配对。
- 配对设备间使用加密连接同步文本、图片和文件记录。
- 用户可关闭指定内容类型的同步，并配置单条内容和单个文件大小上限。
- 使用记录 ID、内容指纹和更新时间去重；删除行为同步为删除标记。
- 置顶状态冲突按最后修改时间处理。
- 设备离线后恢复连接时执行增量补齐，不依赖中心服务器。

### 6.2 第三阶段：云同步

- 提供账号、设备列表、设备撤销和同步状态管理。
- 内容在客户端加密后上传，云端不保存明文剪切板内容。
- 新设备须由已登录设备批准，或通过恢复密钥初始化。
- 支持同步范围、流量限制、仅 Wi-Fi 同步和远程撤销设备授权。
- 云端只承担身份认证、加密数据存储和增量分发，不参与内容搜索。
- 密码及用户标记的敏感记录默认不同步，只有逐项明确授权后才能发送。

## 7. 异常处理

- 剪切板被占用时执行短时、有限次数重试，避免阻塞界面线程。
- 单条图片过大、格式不支持或内容读取失败时跳过该记录，不影响后续监听。
- 文件移动或删除后保留历史记录并显示失效状态，不尝试自动恢复文件。
- 全局快捷键被占用时提示冲突并要求用户重新设置。
- 数据写入失败时提示存储异常，保留应用运行能力并停止接收无法可靠持久化的新记录。
- 未处理异常写入脱敏日志，应用下次启动时恢复已有有效数据。

## 8. 验收标准

- 连续复制文本、图片及多个文件后，历史顺序、类型和预览正确。
- 再次复制相同内容只更新原记录，不增加重复项。
- 在常用 Windows 应用中可通过快捷键调出面板，并使用键盘完成搜索、选择和粘贴。
- 自动粘贴失败时，选中内容仍已写入剪切板并显示明确提示。
- 应用重启后，历史记录、置顶状态、排除规则和设置保持不变。
- 达到 30 天或 5,000 条限制时自动清理普通记录，置顶记录保持不变。
- 暂停监听和应用排除规则立即生效，被排除内容不进入本地存储。
- 数据文件不能由其他 Windows 用户直接读取为明文，日志中不出现剪切板正文。
- 应用在普通用户权限下可安装、启动、运行和卸载。

## 9. 测试范围

- 单元测试覆盖内容指纹、去重、清理规则、搜索、排除规则和同步冲突策略。
- 集成测试覆盖 SQLite 持久化、加密读写、异常恢复及数据迁移边界。
- Windows 交互测试覆盖剪切板监听、全局快捷键、前台窗口恢复和自动粘贴降级。
- 手工兼容性测试至少覆盖记事本、资源管理器、浏览器、Office 类应用和 WPF 应用。
- 性能测试验证 5,000 条混合记录下的启动、面板打开和搜索响应。

## 10. 交付顺序

1. 完成本机数据模型、剪切板监听和历史持久化。
2. 完成快捷面板、搜索、筛选和快速粘贴。
3. 完成置顶、清理、托盘设置及隐私控制。
4. 完成异常恢复、安全验证、性能测试和 MVP 发布。
5. MVP 稳定后单独设计并实施局域网同步。
6. 局域网同步验证完成后单独设计并实施云同步。
